# 테스트와 검증 범위

## 실행 환경과 명령

2026-09-07 기준 Xcode 26.6, iPhone 17 Pro 시뮬레이터(iOS 26.5)에서 실행했다. 프로젝트의 비공개 로컬 설정 파일이 준비된 환경을 사용했다.

프로젝트 루트에서 실행한다. 다른 기기에서는 `xcrun simctl list devices available`로 사용 가능한 시뮬레이터를 확인하고 destination을 바꾼다.

```bash
xcodebuild test -scheme Danogotchi-dev \
  -destination 'platform=iOS Simulator,id=30766493-E52E-4901-A97E-79BD7A299707' \
  -disableAutomaticPackageResolution \
  -only-testing:DanogotchiTests
```

## 저장 실패 처리의 검증

- 변경 전 전체 테스트는 113개가 통과했다. 추가한 저장 실패 회귀 테스트 3개는 기존 코드에서 모두 실패했다.
- Repository의 저장 실패를 테스트용 context로 주입한다. 오류 전파, 미저장 변경 롤백, 성공 신호 차단, 다음 시도의 단일 반영을 검증한다.
- 단어 입력·수정, 목록 삭제, 온보딩 활성 단어장 저장 실패 시 입력과 목록을 유지하고 완료 이벤트를 보내지 않는지 검증한다.
- 퀴즈 답안 저장 실패 시 선택한 답을 유지한다. 경험치 저장 실패의 재시도는 이력을 다시 기록하지 않으며, 성공 후 추가 이벤트에도 중복 적립·완료가 발생하지 않는다.
- 인메모리 테스트와 별도로 임시 SQLite 저장소를 제거·재연결하여 단어장, 단어, 학습 이력, 펫, 삭제 결과를 새 context에서 확인한다.

## 추가로 검증하는 동작

- 출제 최소 4개·최대 20개, 중복 ID 방지, 토너먼트의 두 후보 비교, 이전 이력 기준 경험치와 만점 보너스.
- URLProtocol로 주입한 HTTP 응답을 사용한 URLSession 요청 구성·디코딩·오류·이미지 바이트 전달. 실제 외부 API를 호출하지 않는다.
- 임시 디렉터리에서 이미지 교체와 다운로드·바이트 검증·파일 저장 실패 시 기존 파일 보존. HEIC 요청 실패 후 WebP 요청으로 넘어가는 순서와 실제 바이트 형식에 따른 확장자 판별을 확인한다.
- 가짜 위치 제공자와 날씨 Repository를 사용한 좌표 전달 및 오류 전파.

## 결과와 한계

- 변경 후 테스트: **153개 통과, 실패 0개, 건너뜀 0개**. 선언 수가 아닌 XCTest 실행 결과 기준이다.
- SQLite 재개방은 현재 모델의 저장·복구 검증이다. 구버전 DB 마이그레이션이나 실제 앱 업데이트를 검증한 결과가 아니다.
- 저장 실패는 주입한 오류로 검증했다. 실제 기기의 저장 공간을 소진시키는 테스트는 하지 않았다.
- 퀴즈 채점 테스트는 서로 다른 뜻의 보기로 실행한다. 같은 뜻의 중복 보기 문제는 별도 개선 대상이다.
- 이미지 테스트는 포맷 대체 요청과 파일 교체를 확인한다. 실제 CDN 응답, HEIC·WebP의 전체 포맷 호환성, 이전 배경 복구와 새 선택의 동시 실행은 검증하지 않는다.
- 검색어가 같은 경우의 실패 후 재검색, 실제 위치 권한 UI·요청 취소, 접근성 및 화면 레이아웃은 이번 자동 테스트 범위에 포함하지 않는다.
